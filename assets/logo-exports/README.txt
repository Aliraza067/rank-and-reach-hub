RANK AND REACH HUB — LOGO EXPORTS
==================================

WHAT WAS FIXED
--------------
The original left "R" was a very dark navy (#031e4b) — almost the same
color as the header/footer background (#05070f), so it disappeared on
the actual site. This set fixes that with two color variants instead
of one, plus more spacing between the R's and an arrow accent that
sits fully inside the gap between them (it can no longer touch the
left R).

- Light variant  → navy R (#0a0c10) + blue R (#2454ff) — for white/
  light backgrounds (this is the "PNG Transparent" / general-use file).
- Dark variant    → white R (#ffffff) + blue R (#6f93ff) — for the
  site's dark header and footer, which is what makes the left R
  actually readable where it's really used.
